## Task Contract

- Goal: Let a supervisor model route guidance to a specific Codex worker session,
  such as `gpt5.5xhigh` with a known session ID, so multiple Codex workers can
  operate without receiving each other's plans.
- Non-Goals: Do not launch external model sessions, call model APIs, or depend on
  a vendor-specific session transport. This task records and routes session
  metadata inside the project workflow.
- Dependencies: T-013 supervisor guidance packets and the existing agent
  registry/session state.
- Expected Deliverables:
  - Agent profiles can store a model name and external session ID.
  - `work/start` can record the current worker session ID.
  - `guidance create` can target `to_agent`, `to_model`, and `to_session`.
  - Focus and finish gates only surface/block guidance for the matching worker
    session when a packet is session-scoped.
  - README explains the one-prompt Fable supervisor pattern.
  - Fresh-install regression coverage verifies session-specific routing.
- Definition of Done: Session-scoped guidance is documented, tested, and passes
  workflow checks.
