## Task Contract

- Goal: Prevent a fork that retains an inherited parent workflow ID/lineage but
  loses its trusted instance from loading or resuming the parent's controller
  session.
- Non-Goals: Redesign normal session-key precedence, remove read-only access
  during identity recovery, synchronize separate Git clones, or change general
  task/scope conflict policy.
- Dependencies: T-051 fork isolation, T-052/T-054 independent rejection
  evidence, and the partial T-053 remediation.
- Expected Deliverables: Controller-level fail-closed identity detection,
  hook rejection of `agentctl work/start` for incomplete forks, matching
  installation template behavior, and a fresh-install end-to-end regression
  that executes the actual controller commands after hook checks.
- Definition of Done: An incomplete fork's `status` returns no parent task,
  `work/start` are rejected both through hooks and direct controller calls,
  genuinely read-only hooks remain allowed, the parent record remains
  unchanged, normal resume/fork paths still pass, and the full suite is green.
