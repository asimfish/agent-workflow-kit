- Goal: stop silent repeat failures — when a checkpoint follow-up packet keeps failing (occurrences reaches a threshold), escalate it: mark the packet escalated, ask for a human decision in the run output and triage, and block `finish` on escalated packets for the active task until a human (or explicit override) clears them.
- Non-Goals: cron/daemon scheduling; parallel loop execution; notification transports (mail/IM) beyond files and command output; auto-fixing the underlying failures.
- Dependencies: follow-up packet lifecycle (T-005) and custom loop commands (T-006).
- Expected Deliverables: escalation threshold support in `tools/agentctl.py` (default 3, per-checkpoint override in `.agent/loops/checkpoints.json`), escalated state surfaced by `daily-plan-triage` and `agentctl check`, pre-finish guard for escalated packets with `--ack-escalations` override recorded in the task doc, updated `docs/loop-engineering.md`, template checkpoints file documenting the option.
- Definition of Done: a follow-up packet that reaches the threshold flips to `escalated` exactly once and is listed by triage and `check --mode manual`; `finish` refuses while an escalated packet targets the active task unless acknowledged; a later successful checkpoint still auto-closes escalated packets; `agentctl check --mode manual` passes.
