## Task Contract

- Goal: Turn supervisor-to-Codex dispatch into an evidence-checked acceptance
  workflow so a zero exit code cannot be mistaken for completed worker work.
- Non-Goals: Do not fabricate a live Fable/Codex result, invoke an unknown or
  current Codex session, install a scheduler, weaken provider permissions, or
  add automatic merge/deploy behavior.
- Dependencies: T-021 bounded Codex session transport, T-023 durable runtime,
  T-024 worktree leases, and T-025 supervisor-owned evidence principles.
- Expected Deliverables: A supervisor-owned `guidance verify` command, durable
  acceptance/rejection records, strict route/receipt/ack/task-evidence checks,
  an explicit live-session dogfood procedure, fresh-install regressions, and
  synchronized workflow documentation.
- Definition of Done: A successful fake transport is rejected until the exact
  worker acknowledges guidance and moves the matching task to review or done;
  inconsistent or tampered receipts are rejected; a valid bounded turn produces
  an auditable accepted record; all repository checks pass.
