- Expected Deliverables: Per-conversation session records and heartbeat; generated session status document; atomic scope/file/Git conflict guards; serialized task-document transitions; provider-hook integration; fresh-install documentation and regression tests.
- Definition of Done: Two sessions in one checkout can work on disjoint scopes, cannot claim the same task/scope/file or mutate Git concurrently, stale sessions are visible and explicitly releasable, existing single-session behavior remains compatible, and the full test suite passes.
