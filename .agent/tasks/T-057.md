## Task Contract

- Goal: Give agents upgrading an older installed workflow kit one deterministic transition audit, and prevent different task conversations in one checkout from sharing terminal/default session state when a client fails to provide a unique conversation identity.
- Non-Goals: Downloading a newer kit, replacing `init`, hot-migrating an already running process, auto-releasing session claims, or marking documents as read without an agent actually reading them.
- Dependencies: Existing idempotent `init`, `doctor`, per-conversation session records, document receipts, native lifecycle hooks, Git hooks, and CI checks.
- Expected Deliverables: A read-only `agentctl migrate` report with stable JSON output; SessionStart-generated fallback identities; controller and hook fail-closed guards for terminal/default identity; identity-source visibility; regression coverage for healthy, refresh, restart, old/unknown claims, stale claims, broken installs, and same-terminal concurrent sessions; concise upgrade guidance.
- Definition of Done: Two sessions launched with the same `TERM_SESSION_ID` cannot read or mutate one another's task; supported SessionStart hooks give them distinct identities automatically; missing propagation blocks writes; migration classifications are deterministic and never auto-release claims; project-owned `.agent` history remains unchanged; focused/full suites and manual checks pass; an independent reviewer approves the task.
