## Task Contract

- Goal: Bind a provider payload-only conversation ID to the host-runtime task it
  bootstraps when provider environment propagation is unavailable, without
  allowing a second conversation on the same host runtime to inherit that task.
- Non-Goals: Treat hooks as an OS sandbox; infer identity when neither a provider
  payload nor a unique host runtime exists; implement supervisor-to-worker model
  dispatch.
- Dependencies: T-087 supplies the strict shell/tool guard and the initial
  runtime-session fallback; this task closes the independently reproduced gap in
  that fallback before PR #17 can merge.
- Expected Deliverables: Local provider/runtime binding state under the Git
  common directory, fail-closed conflict handling, source/template parity,
  regressions for SDK-generated payload IDs and competing conversations, and
  updated boundary documentation.
- Definition of Done: A fresh nested provider session whose payload ID is absent
  from its process environment can run `agentctl work` and retain its task on
  later mutating hooks; a different payload on the same active runtime is
  blocked; fork and explicit-instance isolation remains green; focused, full,
  install, static, and real nested-CLI dogfood checks pass; an independent
  reviewer approves the worker task before merge.
