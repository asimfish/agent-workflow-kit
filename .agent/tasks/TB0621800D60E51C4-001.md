## Task Contract

- Goal: implement the final multi-session architecture so independent
  conversations, forked/copied histories, background runs, resources, files,
  upgrades, and bounded loops remain attributable without slowing normal work.
- Non-Goals: a hosted central coordinator; silent takeover of active work;
  automatic deletion of dirty worktrees or experiment outputs; making the
  optional Fable-to-Codex transport a core dependency; OS sandboxing untrusted
  arbitrary processes in the default mode.
- Dependencies: build on the concurrent-session, fork isolation, worktree,
  document-ownership, loop, and hook safeguards already merged in `main`.
- Expected Deliverables: canonical per-task records and generated views; unified
  execution/run/resource leases; fork-history rebinding; incremental file and
  output attribution; task-type worktree policy; protocol upgrade barrier;
  bounded loop integration; migration, regression, performance, and fresh
  install evidence.
- Definition of Done: all new unit and end-to-end tests pass on a clean install;
  copied-history sessions cannot inherit parent authority; disjoint sessions
  run concurrently; conflicting resources and writes serialize or fail closed;
  background ownership survives conversation exit; views regenerate from
  canonical records; old protocol writers cannot cross an upgrade barrier; the
  common hook path remains within its documented latency budget.
