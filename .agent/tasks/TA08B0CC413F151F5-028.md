## Task Contract

- Goal: make a machine-wide resource lock left behind by another checkout on the same host diagnosable and recoverable from the checkout that is actually blocked, without ever releasing a lock whose holder may still be working.
- Non-Goals: no change to in-checkout lease semantics or orphan-sweep grace windows; remote (`ssh://`) locks stay report-only.
- Dependencies: builds on the interlock work in #45/#46 (holder liveness, `--force-stale`, doctor findings).
- Expected Deliverables: owner record carries the holder checkout; `_foreign_lock_liveness` classifies foreign holders from that checkout's registry and sessions; `resource acquire` auto-releases holders proven dead (released/terminal/missing past grace) and otherwise names state + recovery; `resource release --lock <resource> --force-stale --reason` for stale/checkout_gone/legacy holders with an audit row; `doctor` lists machine-wide locks without a live holder; docs (multi-session-execution, READMEs, CHANGELOG); two-checkout regression tests.
- Definition of Done: the original replay (project A acquires `gpu:0`, A is deleted, project B is blocked) ends with B's `doctor` naming the lock and command, the command releasing it, and B acquiring; full suite passes; independent review approves; PR merged with green CI.
