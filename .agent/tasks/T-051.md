## Task Contract

- Goal: Prevent a conversation fork/clone from silently reusing its parent
  conversation's runtime task session, including when the child inherited the
  parent's workflow environment.
- Non-Goals: Synchronize independent full Git clones over the network; infer two
  distinct conversations when the host exposes no differing runtime, hook, or
  fork identity; replace task/scope/file conflict policy.
- Dependencies: T-038 multi-session records and T-040 identity precedence fixes.
- Expected Deliverables: Fork-aware hook identity propagation, stale inherited
  identity rejection, lineage visibility, installation-safe templates,
  documentation, and fresh-install regressions.
- Definition of Done: Parent and fork sessions receive different keys in one
  checkout, same-task/overlapping work remains blocked, disjoint work remains
  independent, ambiguous fork hooks fail closed, installed templates match the
  source implementation, and the full regression suite passes.
