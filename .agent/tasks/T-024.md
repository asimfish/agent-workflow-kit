## Task Contract

- Goal: Provide a safe project-level command for creating, inspecting, and releasing dedicated Git worktrees for parallel agents without sharing an index or working directory.
- Non-Goals: No automatic worktree pool, background scheduler, branch deletion, force removal, merge automation, cross-host coordination, or implicit GitHub push.
- Dependencies: T-023 provides crash-safe local process and execution leases; existing Git standards define task branches and worktree isolation requirements.
- Expected Deliverables: A Git-common-dir lease registry; `worktree create`, `worktree list`, and `worktree release`; clean-baseline and committed-task guards; fresh-install regressions; concise operator and supervisor documentation.
- Definition of Done: From a fresh installed Git project, an agent can create one task-scoped worktree and branch, duplicate allocation is rejected, every worktree sees the same lease registry, dirty or current worktrees cannot be released, a clean leased worktree can be removed without deleting its branch, and all workflow tests and gates pass.
